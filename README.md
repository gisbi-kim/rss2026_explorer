# RSS 2026 Paper Explorer

Static paper explorer for Robotics: Science and Systems 2026 accepted papers.

Live site:

- https://gisbi-kim.github.io/rss2026_explorer/

Source data:

- `Accepted Papers - Robotics_ Science and Systems.html` from the local Downloads folder.
- `data/rss2026_papers_1_210_abstracts.txt`: abstracts collected from official paper detail pages 1-210.

Contents:

- `index.html`: standalone explorer with embedded paper data.
- `build_rss_explorer.py`: parser and static HTML generator.
- `data/rss2026_papers_1_210_abstracts.txt`: abstract source used by the generator.
